# 둘이 — 커플 공간 웹앱

회원가입·로그인, 초대 코드로 두 계정 연결, 실시간 채팅, 비공개 사진 앨범을 갖춘 모바일 우선 웹앱 초안입니다.

## 구성

- 웹 화면: HTML, CSS, JavaScript
- 계정·데이터·실시간 메시지·사진 저장: Supabase
- 공개 웹 주소: GitHub 저장소를 Vercel에 연결해 배포

두 사람이 서로 다른 기기에서 같은 기록을 보려면 Supabase 프로젝트 설정이 필요합니다.

## 1. Supabase 설정

1. Supabase에서 새 프로젝트를 만듭니다.
2. **SQL Editor**에서 `schema.sql` 전체를 실행합니다. 계정 연결, 메시지·사진 테이블, 접근 정책, 비공개 사진 저장소, 실시간 업데이트가 설정됩니다.
3. **Project Settings → API**에서 Project URL과 publishable key(또는 anon public key)를 확인합니다.
4. `app.js` 맨 위의 `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` 값을 본인 프로젝트 값으로 바꿉니다.
5. **Authentication → URL Configuration**에서 배포 후 받을 주소를 Site URL 및 Redirect URLs에 추가합니다.

브라우저 코드에는 공개 키만 사용하세요. `service_role` 키는 브라우저에 넣지 마세요. 데이터베이스 RLS와 Storage 정책은 연결된 두 계정만 대화와 사진에 접근하도록 제한합니다.

## 2. GitHub와 웹 배포

1. 이 폴더의 파일을 새 GitHub 저장소 루트에 올립니다.
2. Vercel에서 해당 GitHub 저장소를 가져옵니다.
3. 정적 사이트로 배포합니다. 빌드 명령은 비우고 출력 폴더는 프로젝트 루트(`.`)로 설정합니다.
4. 배포 완료 후 생성된 HTTPS 주소를 휴대폰과 데스크톱에서 열어 확인합니다.

공개 링크를 직접 보내는 데 검색엔진 등록은 필요하지 않습니다. 네이버·구글 검색 결과에 표시하려면 별도 색인 신청과 사이트 정보 설정이 필요합니다.

## 첫 사용

1. 두 사람이 이메일로 회원가입합니다. 이메일 확인이 설정돼 있으면 확인 링크를 누릅니다.
2. 한 사람은 `새 공간 만들기`로 코드를 만든 뒤 상대에게 전달합니다.
3. 상대방은 로그인해서 초대 코드를 입력합니다.
4. 대화 탭에서 메시지를 주고받고, 사진첩 탭에서 JPG/PNG/WEBP 사진(최대 10MB)을 저장합니다.

## 현재 범위

현재 초안에는 가입·로그인, 한 쌍 연결, 실시간 텍스트 채팅, 사진 업로드·열람·삭제가 포함됩니다. 공유 캘린더, 기념일, 알림, 비밀번호 재설정, 계정 및 공간 탈퇴는 다음 단계 기능입니다. 실제 사용 전 두 개의 테스트 계정으로 권한과 연결 흐름을 확인하고, 포트폴리오 공개에는 테스트용 계정과 사진을 사용하세요.
